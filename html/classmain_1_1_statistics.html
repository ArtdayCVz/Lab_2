Detailed Description

A class for performing descriptive statistics on numerical datasets.

This class provides methods to calculate central tendency (mean, median, mode) and measures of variability (variance, standard deviation). It handles validation of input data to ensure statistical operations are performed on valid numerical lists.

◆ mode()

main.Statistics.mode ( self)

Calculates the mode (the most frequent value).

This method handles three scenarios:

  1. Unimodal: One clear most frequent value. Returns that value.
  2. Multimodal: Multiple values share the highest frequency. Returns a list of these values.
  3. No Mode: All values are unique. Returns None.
Returns
(int | float | list | None) The mode value(s) or None.
stats = Statistics([1, 2, 2, 3])
print(stats.mode()) # Output: 2
stats = Statistics([1, 1, 2, 2])
print(stats.mode()) # Output: [1, 2]
