\doxysubsection{Detailed Description}
A class for performing descriptive statistics on numerical datasets. 

This class provides methods to calculate central tendency (mean, median, mode) and measures of variability (variance, standard deviation). It handles validation of input data to ensure statistical operations are performed on valid numerical lists.
