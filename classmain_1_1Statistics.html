Detailed Description

A class for performing descriptive statistics on numerical datasets.

This class provides methods to compute measures of central tendency (mean, median, mode) and measures of statistical variability (variance, standard deviation). It validates the input data before applying mathematical operations.

Example usage:
stats = Statistics([1, 2, 3])
print(stats.mean())

Computes the median of the dataset.

If the number of elements is odd, the middle number is returned. If the number is even, the median is the average of the two central numbers.

Returns
The median value.
Example:
# Odd number of elements

# Returns 3
# Even number of elements

# Returns 4.0

◆ mode()

main.Statistics.mode (   self)

Computes the statistical mode.

The mode is the most frequently occurring value in the dataset.

  • If a single value is most frequent, that value is returned.
  • If multiple values share the same highest frequency, a list is returned.
  • If all values appear only once, the method returns None.
Returns
int | float | list | None The mode or list of modes.
Example:
# Single mode
Statistics([1, 2, 2, 3]).mode() # Returns 2
# Multiple modes
Statistics([1, 1, 2, 2]).mode() # Returns [1, 2]
# No mode (all unique)
Statistics([1, 2, 3]).mode() # Returns None
